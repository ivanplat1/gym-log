# gym-log

Трекер тренировок и питания в духе Strong / MIRIN: степперы веса и повторов, таймер отдыха, дневник еды.

## На телефоне

**https://ivanplat1.github.io/gym-log/**

Добавь на экран «Домой» (PWA).

## Возможности

- Пустая тренировка → упражнения из базы → степперы кг/повторы → запись подхода
- Таймер отдыха после подхода (−15 / +15)
- Подсказка с прошлой сессии
- Питание: пресеты, ккал/БЖУ, цели, приёмы пищи
- **Здоровье**: сон / шаги / активные ккал (Mi Band → Apple Health → Ярлык iOS)
- Журнал с детализацией
- Офлайн PWA · данные в `localStorage`

## Сон и активность с Mi Band / iPhone

Браузер не читает HealthKit и BLE напрямую. Рабочая схема:

1. Mi Fitness → сторонние данные → **Apple Health** (сон, шаги, пульс)
2. Ярлык на iPhone каждое утро открывает ссылку вида  
   `https://ivanplat1.github.io/gym-log/health?date=…&sleepMin=…&steps=…&activeKcal=…`
3. gym-log сохраняет день в журнал на вкладке **Сон**

Подробности и пример ссылки — в приложении: **Сон → Настроить автоимпорт**.
