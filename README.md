# СТАРТ · gym-log

Журнал программы **старт (масса / форма)** — сплит A / B / C.

## На телефоне

После merge в `main` и включения GitHub Pages:

**https://ivanplat1.github.io/gym-log/**

В GitHub: Settings → Pages → Source = **GitHub Actions**.  
В Safari/Chrome на телефоне: «На экран „Домой“» — открывается как приложение. Данные хранятся в браузере телефона.

## Возможности

- Дни A (зал · верх), B (зал · низ + задняя цепь), C (дом · объём)
- Лог подходов: вес × повторы + запас (RIR)
- Подсказка веса по прошлой сессии и правилу прогрессии (+2,5 кг)
- Правила плеча, замены, «не делать пока»
- Данные в `localStorage` (офлайн на телефоне)

## Запуск локально

```bash
npm install
npm run dev
```

Сборка: `npm run build`
