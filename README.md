# gym-log

Трекер тренировок и питания. Без готовой программы — выбираешь упражнения из списка и логируешь подходы.

## На телефоне

**https://ivanplat1.github.io/gym-log/**

(после merge и деплоя Pages)

## Возможности

- Список базовых упражнений с поиском и фильтрами по группам
- Лог подходов: кг × повторы (или секунды)
- Подсказка веса с прошлой сессии
- Питание: пресеты продуктов, ккал / БЖУ, цели дня
- Журнал тренировок · данные в `localStorage`

## Запуск

```bash
npm install
npm run dev
```
